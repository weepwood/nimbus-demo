所有主文档都位于 src/content/docs/，支持 Markdown 和 MDX。

## 创建文档

在 src/content/docs 下创建一个新的 MDX 文件：

~~~mdx title="src/content/docs/my-guide.mdx"
---
title: 我的新指南
description: 一篇新的 Nimbus 文档。
sidebar:
  order: 6
---

在这里编写正文。

## 第一部分

可以使用 Markdown 标题、列表和代码块。
~~~

Nimbus 会根据文件位置生成路由并通过 sidebar 的规则管理导航顺序。

## Frontmatter 配置

| 字段 | 用途 |
| --- | --- |
| title | 文档标题，必填 |
| description | 页面简介与 SEO 描述 |
| sidebar.order | 侧边栏显示顺序 |
| draft | 是否作为草稿 |
| tableOfContents | 控制右侧章节目录 |

<Aside type="note">
  Frontmatter 由内容集合和 Schema 校验。生产环境构建时可以发现无效字段或格式。
</Aside>

## 文档质量

运行下列命令进行检查：

~~~bash
pnpm typecheck
pnpm build
pnpm lint:docs
~~~

Nimbus 同时可以生成供 AI Agent 使用的 Markdown 页面、llms.txt 和 llms-full.txt 文件。更多详细内容请阅读 [官方写作指南](https://nimbus-docs.com/writing/)。
