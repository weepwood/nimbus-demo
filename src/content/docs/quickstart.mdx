本项目使用 Cloudflare Nimbus 官方 Starter 构建，页面由 Astro 和 MDX 驱动。

<Aside type="tip" title="前置条件">
  建议安装 Node.js 24 与 pnpm 10。Nimbus 官方要求 Node.js 22.23.4 或更新版本。
</Aside>

## 安装并启动

<Steps>
  <Step title="克隆项目">
    ~~~bash
    git clone https://github.com/weepwood/nimbus-demo.git
    cd nimbus-demo
    ~~~
  </Step>
  <Step title="安装依赖">
    ~~~bash
    corepack enable
    pnpm install
    ~~~
  </Step>
  <Step title="启动开发服务器">
    ~~~bash
    pnpm dev
    ~~~

    访问控制台输出的本地地址。此项目配置了 /nimbus-demo 子路径。
  </Step>
  <Step title="修改你的第一页">
    打开 src/content/docs/index.mdx，修改首页文案。保存后 Astro 会自动更新页面。
  </Step>
</Steps>
