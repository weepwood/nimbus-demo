Nimbus Studio 保留 Nimbus 官方组件架构，重新设计其视觉令牌和品牌元素。风格参考 [Cloudflare Developers](https://developers.cloudflare.com/) 的信息密度、文档导航和功能性设计原则，但使用独立标志，不属于 Cloudflare 官方产品。

## 设计原则

- **高信息密度，低视觉噪声：** 使用中性色、细分隔线和较少的装饰。
- **强调色有用途：** 橙色用于操作入口、选中状态、重点信息和图标。
- **字体明确分工：** 界面与正文使用无衬线字体，代码使用等宽字体。
- **组件先于页面：** 保持导航、卡片、控件和状态语义的一致性。
- **遵循用户偏好：** 深浅色切换、键盘操作与响应式布局。

## 当前主题令牌

以下代码与项目实际的 `src/styles/globals.css` 一致。

~~~css title="src/styles/globals.css"
:root {
  --nb-background: #ffffff;
  --nb-foreground: #202124;
  --nb-card: #ffffff;
  --nb-muted: #f8f8f7;
  --nb-brand: #bd520c;
  --nb-primary: #bd520c;
  --nb-border: #e9e8e5;
  --nb-radius: 0.625rem;
}

[data-mode="dark"] {
  --nb-background: #141416;
  --nb-foreground: #f5f5f4;
  --nb-card: #1b1b1d;
  --nb-brand: #ffab70;
}
~~~

Nimbus 官方 Starter 以 CSS 变量提供语义色彩接口，并在 Tailwind CSS 4 中使用 `@theme` 暴露这些变量。项目同时使用 HEX 与 OKLCH 表示颜色；OKLCH 主要用于混合、状态与派生色。

## 字体系统

当前项目自托管 **Inter Variable** 和 **JetBrains Mono Variable** 的 Latin 字形，并在中文环境使用系统字体回退，不要求浏览器访问 Google Fonts：

~~~css
--nb-font-sans:
  "Inter Variable", "Inter",
  "Noto Sans CJK SC", "PingFang SC",
  "Microsoft YaHei", "Segoe UI", sans-serif;

--nb-font-mono:
  "JetBrains Mono Variable", "JetBrains Mono",
  ui-monospace, Consolas, monospace;
~~~

系统将按字符选择可用字形。不同操作系统的中文字形与字重可能存在细微差异。

## Phosphor 图标

Nimbus 使用 Iconify 格式的 SVG 图标，本站统一选用 Phosphor（`ph:`）系列。图标使用 `currentColor`，可随主题和状态改变颜色。

~~~mdx

~~~

建议在同一页面内统一图标的视觉尺寸：导航 16–18px、功能卡片 20–24px、操作按钮 16px。

## 主题切换

点击顶部导航的主题按钮，即可切换明暗模式。选择会存储在浏览器本地；未设置偏好时采用系统配色方案。

<Aside type="tip">
  自定义品牌、颜色和字体时，先调整全局令牌，再修改局部组件。避免在每个页面重复散落颜色常量。
</Aside>
